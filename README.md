# Wine Catalog

A full-stack wine catalog app built with Next.js, TypeScript, Prisma, and PostgreSQL.

## Live Demo

[georgian-wine-catalog.netlify.app](https://georgian-wine-catalog.netlify.app)

## Tech Stack

- Next.js 15
- TypeScript
- Prisma 7
- Neon PostgreSQL
- Tailwind CSS

## Features

- Browse wines
- Search by name
- Add / Edit / Delete wines
