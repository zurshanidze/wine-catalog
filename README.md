# Wine Catalog

A full-stack Georgian wine catalog built with Next.js, TypeScript, Prisma, and PostgreSQL.

## Live Demo

[georgian-wine-catalog.netlify.app](https://georgian-wine-catalog.netlify.app)

## Tech Stack

- Next.js 15
- TypeScript
- Prisma 7
- Neon PostgreSQL
- Tailwind CSS

## Features

- Browse Georgian wines
- Search by name
- Authentication (register, login, logout)
- Role-based access control (admin/user)
- Admin: Add, Edit, Delete wines
- Guest: Browse and search only
